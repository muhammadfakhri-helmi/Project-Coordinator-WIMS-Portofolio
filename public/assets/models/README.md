# models/

Empty on purpose. The wellhead/X-mas tree is generated procedurally in
`src/three/wellhead.js`, so no model file is shipped.

To use a GLB instead, place an original or properly licensed `.glb` here
(preferably Draco- or Meshopt-compressed, under 10 MB) and follow
"Replacing the procedural model with a GLB" in the root README. Record its
creator, source URL, license and modifications in `docs/ASSET_MANIFEST.md`.
